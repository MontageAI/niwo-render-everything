# 横屏信息动效版备料

仅当用户明确选择 `landscape-editorial-motion-v1` 时使用本节。普通横屏、竖屏视频和竖屏信息版沿用原流程。`editorial.prepared_for` 只说明素材面向哪个版面；用户仍需在 Niwo 渲染界面选择该版面。

## 按定稿口播找画面

所有视频底片必须为横屏；打包前用 `ffprobe` 核对显示宽高，并运行 `validate_bundle.py --layout landscape-editorial-motion-v1`。

把用户已确认的 `script` 按叙事意思分段，给每段稳定的 `id`、原文连续摘录 `script_anchor`、叙事角色 `role` 和可见的画面目标 `visual_goal`。片名另填 `title_text`，用 `title_anchor` 指向文案原文。不要修改口播来迁就素材；分段只存在于备料说明中。

逐段搜索、下载与画面目标直接相关的真实视频。先按口播时长规划：纯 UI 画面只占最终可见时长的 20%～25%，其余 75%～80% 每一帧都要有真实视频，可用满幅、纸面视频窗口或视频与图解同屏。为每个需要视频的段落继续检索，直到有足够的**不同视频**覆盖该段；一条视频在全片只使用一次，同一原片的重复下载、改名或相同画面的不同裁切也不能算新视频。仅统计每条不重复视频计划实际使用的动态画面时长，逐段核对，不能把一个段落的富余时长拿来掩盖另一段缺片。

素材可以裁成短片，也可以在 manifest 标出有效选段。通过 `ffprobe` 核对每段实际时长，只累计可用窗口：裁好的片段算完整时长，长原片算 `clip_end_seconds - clip_start_seconds`，只写起点时算到原片结尾。让不重复视频的可用窗口总和至少达到目标时长的 90%；有实测配音时长后，改用实测值复核。这个备料容量为 75%～80% 的实际视频画面留出剪辑余量，不能靠慢放、冻结、循环或静态图片补足。若分镜中的 `startRatio/endRatio` 留出纯 UI 空档，要把空档计入 20%～25%，不能只按带视频的场景数量估算。逐段人工检查主体、语义与片段画面，最终仍以成片的逐帧可见时长验收。

另从**包内已声明的真实视频**抽一帧并抠出人物或物体主体，至少交一张带透明区域且主体可见的 PNG 前景。`derived_from.file` 精确指向该视频，`at_seconds` 是在该文件内的抽帧秒数；如文件已裁过，按裁后文件从零计时。`focus` 可记录源画面的主体框，用 0 到 1 的相对坐标，供说明构图使用；当前纸面编排不据此对实景物体画圈、引线或跟踪标注。前景 PNG 是视频派生的叠层，不计入视频时长。普通图片仍可用于其他用途，但不能标作 `foreground`。

## 备料元数据

`content.json` 增加 `editorial`，段落字段见 [content 协议](content-schema.md#editorial)。每个新横屏素材在 `manifest.json` 的条目中增加 `editorial`；视频底片标 `footage`，透明 PNG 叠层标 `foreground`，字段见 [manifest 协议](manifest-schema.md#editorial)。`segment_ids` 引用已声明的段落编号；`title_candidate` 只提示该素材可作片名镜头，`subject` 和 `focus` 说明主体与构图。元数据负责传达素材用途，不是完整分镜，也不保证最终画面一定采用该素材。

这个版面的 `images/` 和 `videos/` 中不要留未写进 manifest 的文件；新增或删除素材后要同步修改清单并重新校验。

5 分钟片子需要较长的有效视频窗口，但 Niwo 浏览器上传只接收最多 100 个媒体文件、最大 200 MiB 的 ZIP。先裁掉无用片段，再用合适的分辨率和码率压缩视频；不要通过慢放、冻结或重复选段凑时长。新横屏本地校验器按 `images/`、`videos/` 的实际文件数检查 100 个上限，并保守地把素材包目录内所有文件的原始字节合计限制在 195 MiB，为 ZIP 文件头和目录留出余量。打包前清理不需要的文件，打包后再核对最终 ZIP 不超过 200 MiB。普通版面沿用原有校验口径。

## 验收

运行 `validate_bundle.py` 时必须给 `--target-seconds` 或 `--narration-seconds`。后一项有值时优先采用。校验器核对 JSON 结构、原文锚点、段落关联、视频文件和选段、PNG 透明度、包内视频来源与抽帧位置，并计算 90% 的备料容量。还需人工检查不同文件是否为同一视频、视频主体、段落语义、抠图边缘和最终编排；校验器无法证明最终画面的视频真实可见比例。成片验收须按转场重叠和视频槽入退场核算纯 UI 20%～25%、有视频 75%～80%，且没有重复视频。
